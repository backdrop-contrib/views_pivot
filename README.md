# Views Pivot

This module allows to output the result of a Backdrop View as a pivot table.

## Installation

- Install this module using the official Backdrop CMS instructions at
  https://backdropcms.org/guide/modules.

## Configuration

- Create a View and select Pivot as the format.
- Configure pivot rows, columns and aggregates in the settings.
